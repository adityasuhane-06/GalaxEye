# Evaluation Reports & Visualizations

This directory contains the core visual evidence and statistical analysis for the Building-Guided EO-SAR Change Detection model.

- **figures/**: Contains data audit visualizations (e.g., class imbalance charts) and side-by-side inference prediction maps.
- **JSON files**: Raw statistical data extracted during the EDA phase.
- **technical_report.md/pdf**: Detailed architectural and analytical write-up.
